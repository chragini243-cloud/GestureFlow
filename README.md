GestureFlow – Hands-Free Digital Instruction Assistant

GestureFlow is a hands-free digital instruction assistant that helps users follow step-by-step instructions using hand gestures and voice commands.

Features

- Six Activity Categories: Cooking, Fitness, Baking, Workshop, Learning, and Custom Instructions.
- Voice Commands: Next, Previous, Read, Pause, Resume, and Stop.
- Hand Gesture Control: Navigate instructions without touching the keyboard or mouse.
- Video Library: Play preloaded videos and upload personal videos.
- Hands-Free Video Controls: Forward, Backward, Play, Pause, Resume, and Stop.
- Text-to-Speech: Listen to instructions while performing activities.
- Custom Instructions: Create and follow your own step-by-step instructions.
- Timers: Use timers for supported activities.

Technologies Used

- HTML
- CSS
- JavaScript
- Python
- OpenCV
- MediaPipe
- Flask
- Web Speech API
